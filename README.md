# साड़ल Kitchen

A fictional cloud-kitchen trolling website built as a UI/UX + front-end practice project.

## Stack
- HTML
- CSS
- Vanilla JavaScript
- Google Fonts: DM Sans, Playfair Display, Noto Sans Devanagari

## Run
Open `index.html` in a browser, or use VS Code + Live Server.

## Main interactions
- Responsive navigation
- Mobile menu
- Scroll reveal animations
- Menu category filtering
- Add-to-cart drawer
- Quantity controls
- Fake checkout
- Review slider
- Animated cockroach Easter egg
- Fake map interaction

## Design
60 / 30 / 10:
- 60% Warm Cream: #F4EBDD
- 30% Deep Charcoal: #171512
- 10% Golden Amber: #C58B2A

The site uses the structural/editorial feel of the referenced MADIE website as inspiration, but the content, branding, layout details, assets, and interactions are original to साड़ल Kitchen.
